# Irrigation Method Images

Place your irrigation system images in this folder. The application expects the following files:

## Required Files

- **drip.jpg** - Drip irrigation system image
- **sprinkler.jpg** - Sprinkler irrigation system image
- **furrow.jpg** - Furrow/surface flow irrigation image
- **rainwater.jpg** - Rainwater harvesting/collection system image

## Image Specifications

- **Format**: JPEG or PNG
- **Recommended Size**: 1200x600px (or similar landscape ratio)
- **Quality**: High-quality photos showing the actual irrigation method in action
- **File Naming**: Must match the names above exactly (lowercase)

## How It Works

When an irrigation method is recommended, the corresponding image will be displayed in the irrigation advice card. The app shows practical implementation photos of each irrigation technique tailored to the field conditions.
