# Crop Images

Place your crop images in this folder. The application expects the following files:

## Required Files

- **paddy.jpg** - Rice paddy field image
- **banana.jpg** - Banana plantation image
- **groundnut.jpg** - Groundnut/peanut field image
- **maize.jpg** - Corn/maize field image
- **millet.jpg** - Millet field image
- **pulse.jpg** - Pulse crops (lentils, chickpeas, etc.) image

## Image Specifications

- **Format**: JPEG or PNG
- **Recommended Size**: 1200x600px (or similar landscape ratio)
- **Quality**: High-quality photos showing the actual crop in the field
- **File Naming**: Must match the names above exactly (lowercase)

## How It Works

When a crop is recommended based on water availability, the corresponding image will be displayed in the recommendations card. The app will show only the single recommended crop based on current groundwater conditions.
